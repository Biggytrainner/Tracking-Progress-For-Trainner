# Biggy Trainer App — ฐานข้อมูลกลางบน Netlify (ไม่มีหน้าล็อกอิน)

ข้อมูลทั้งหมดเก็บใน Netlify Blobs (มีในตัว Netlify) ทุกเครื่องที่เปิดเว็บนี้เห็นข้อมูลชุดเดียวกัน

## ติดตั้ง
1. อัปโหลด**ไฟล์ข้างใน** zip นี้ขึ้น GitHub (index.html, netlify.toml, package.json, โฟลเดอร์ netlify) — หน้า repo ต้องเห็น index.html ที่ราก
2. Netlify → Add new site → Import from Git → เลือก repo → Deploy
3. (แนะนำ) ตั้งรหัสป้องกัน: Site configuration → Environment variables → `APP_KEY` = รหัสลับ แล้ว Trigger deploy ใหม่
   - แอปจะถามรหัสครั้งเดียวต่อเครื่อง แล้วจำไว้ (ไม่ใช่หน้าล็อกอิน)
   - ถ้าไม่ตั้ง ใครรู้ลิงก์เว็บจะอ่านและแก้ข้อมูลลูกค้าได้

## หมายเหตุ
- ถ้าเคยสมัครบัญชีไว้ในเวอร์ชันที่มีล็อกอิน ข้อมูลที่ค้างในเบราว์เซอร์จะถูกดึงขึ้นฐานข้อมูลกลางอัตโนมัติเมื่อเปิดแอป
- ข้อมูลสุขภาพลูกค้าอยู่ใต้ PDPA
