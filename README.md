# Biggy Trainer App — ฐานข้อมูลกลางบน Netlify

ข้อมูลทั้งหมดเก็บใน Netlify Blobs (ไฟล์ index.html ต้องอยู่ที่ราก repo ไม่ใช่ในโฟลเดอร์ย่อย) (มีในตัว Netlify ไม่ต้องสมัครฐานข้อมูลเพิ่ม)

## วิธีติดตั้ง (ผ่าน GitHub — แนะนำ)
1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดทุกไฟล์ในโฟลเดอร์นี้ (รักษาโครงสร้างโฟลเดอร์ไว้)
2. เข้า app.netlify.com → Add new site → Import an existing project → เลือก repo
3. ค่า Build ปล่อยตามเดิม (อ่านจาก netlify.toml) แล้วกด Deploy
4. **ตั้งรหัสป้องกัน (ควรทำ):** Site configuration → Environment variables → เพิ่ม `APP_KEY` = รหัสลับที่ตั้งเอง แล้ว Deploy ใหม่
   - แอปจะถามรหัสครั้งแรกบนแต่ละเครื่อง แล้วจำไว้
   - ถ้าไม่ตั้ง ใครที่รู้ลิงก์จะอ่านและเขียนข้อมูลลูกค้าได้
5. ตั้งโดเมนของตัวเอง: Domain management → Add a domain

## วิธีติดตั้ง (ผ่านคำสั่ง)
```
npm i -g netlify-cli
npm install
netlify deploy --prod
```
(ทดสอบในเครื่องใช้ `netlify dev`)

## ย้ายข้อมูลจากแอปเดิม
เปิดแอปเดิม → Export ไฟล์ .json → เปิดแอปบน Netlify → Import ข้อมูลจะขึ้นฐานข้อมูลกลางอัตโนมัติ

## หมายเหตุ
- จุดสถานะข้างชื่อแอป: เขียว = ซิงก์แล้ว, เหลือง = กำลังซิงก์, แดง = ซิงก์ไม่สำเร็จ (ข้อมูลยังเก็บในเครื่อง)
- แอปดึงข้อมูลใหม่ทุก 15 วินาที ถ้าสองคนแก้ข้อมูลเดียวกันพร้อมกัน ฉบับที่บันทึกทีหลังจะเป็นฉบับที่ใช้
- ข้อมูลสุขภาพลูกค้าอยู่ใต้ PDPA: ควรตั้ง APP_KEY และแจ้งลูกค้าก่อนเก็บข้อมูล
